# Uciekająca kropka

Trudny wariant gry „Łap kropkę”. Cel wykrywa zbliżający się wskaźnik i ucieka. Po dwóch unikach przez 1,2 sekundy jest zmęczony i można go złapać.

## Sterowanie

- mysz lub rysik: kropka reaguje na zbliżanie kursora;
- ekran dotykowy: przeglądarka wykrywa palec dopiero po dotknięciu ekranu, więc kropka reaguje na dotknięcie w jej pobliżu;
- klawiatura: kropkę można wybrać klawiszem `Tab` i aktywować klawiszem `Enter`.

## Uruchomienie

Gra nie wymaga instalowania zależności. Otwórz `index.html` albo uruchom lokalny serwer w katalogu repozytorium:

```powershell
python -m http.server 8000
```

Następnie otwórz `http://localhost:8000/projekty/uciekajaca-kropka/`.

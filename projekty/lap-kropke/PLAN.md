# Plan projektu „Łap kropkę”

## MVP

- [x] ekran startowy;
- [x] działanie na telefonie i komputerze;
- [x] losowe położenie celu;
- [x] punkt za każde trafienie;
- [x] runda trwająca 20 sekund;
- [x] zakończenie i restart;
- [x] rekord zapisany lokalnie;
- [x] przycisk udostępniania linku;
- [x] publikacja pod publicznym adresem.

## Pomysły po MVP

- wybór czasu rundy;
- cel zmniejszający się wraz z wynikiem;
- tryb dla dwóch graczy na zmianę;
- dźwięki i wibracja telefonu;
- tabela rodzinnych rekordów;
- instalacja gry na ekranie głównym jako PWA.

## Definicja ukończenia

MVP jest ukończone, gdy gra działa w przeglądarce telefonu, można rozegrać pełną rundę, uruchomić ją ponownie i przesłać drugiej osobie publiczny link.
